OUR ANNIVERSARY — A NEW WEBSITE

This is a brand-new, self-contained static website for GitHub Pages.

IMPORTANT:
- Keep index.html and the assets folder together in the repository root.
- Upload the contents of this folder (not the ZIP file itself).
- GitHub Pages should use branch: main, folder: /(root).
- The site has no music and needs no build step.
- It uses Google Fonts when online; system font fallbacks are included.
